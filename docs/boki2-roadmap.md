### なぜ「2026年度中」に決着させるべきか（重要）

2027年度に**大幅な出題範囲改定**が予告されています。

- 実務上の手形・小切手廃止に伴い、**手形・小切手が出題されなくなる**
- **リース会計基準の改定**により、リース取引の仕訳が変わる
- 2級 → 3級への範囲移動、1級 → 2級への範囲移動（売掛債権のファクタリング等）

つまり **2027年4月以降は今の教材が使えなくなり、学び直しコストが発生する**ということです。
2026年度中（統一試験なら11/15・2027年2/28、ネット試験なら2027年3月上旬まで）に取り切るのが圧倒的に有利です。

なお **2026年度の試験範囲は2022年度適用の出題区分表のまま**で、大きな変更はありません。
（企業会計基準第37号「期中財務諸表に関する会計基準」が2026年度から出題対象に追加されています。該当級は公式の出題区分表で確認してください。）

→ **教材は必ず「2026年度版」を購入すること。** 2025年度版の中古やメルカリ品は微妙に危険です。

## 1. 試験の基本仕様（3級との違いを最初に頭に入れる）

| | 3級 | 2級 |
|---|---|---|
| 試験時間 | 60分 | **90分** |
| 出題 | 商業簿記のみ | **商業簿記60点 ＋ 工業簿記40点** |
| 合格点 | 70点 | 70点 |
| 合格率 | 約40% | **約20〜25%（回によって10%台も）** |

### 大問構成と配点

| 大問 | 分野 | 配点 | 内容 | 目標点 | 目安時間 |
|---|---|---|---|---|---|
| 第1問 | 商簿 | 20点 | 仕訳5問 | **16〜20点** | 10分 |
| 第2問 | 商簿 | 20点 | 連結／株主資本等変動計算書／個別論点 | 8〜14点 | 20分 |
| 第3問 | 商簿 | 20点 | 財務諸表作成・精算表 | 12〜16点 | 25分 |
| 第4問 | 工簿 | 28点 | (1)仕訳3問12点 (2)費目別・個別・総合原価計算16点 | **24〜28点** | 25分 |
| 第5問 | 工簿 | 12点 | 標準原価計算／直接原価計算(CVP) | **10〜12点** | 10分 |

**戦略の核心: 工業簿記40点をほぼ取り切る。**
工簿は範囲が狭く、パターンが安定していて、努力が素直に点数になります。
一方、第2問（特に連結会計）は難化することがあり、ここに時間を溶かすと総崩れします。

**解く順番は「第1問 → 第4問 → 第5問 → 第3問 → 第2問」を推奨。**
確実に取れる工簿を先に確保し、最後に第2問へ残り時間を全部注ぎます。

### Phase 0: 3級の記憶を叩き起こす（7/29 〜 8/9・2週・20時間）

1年のブランクがあるので、**ここを飛ばすと Phase 1 で必ず詰まります。** ただし2週間で切り上げること。

**やること**
- 3級のテキストを**通読しない**。代わりに3級の過去問・予想問題を **2回分だけ通しで解く**（各60分）
- 点数が60点未満だった論点だけ、テキストの該当ページに戻る
- 以下は2級で毎回前提として使うので、確実に手が動く状態にする
  - 仕訳の5要素と貸借のルール、勘定連絡
  - 三分法／売上原価の算定（仕入・繰越商品・売上原価）
  - 決算整理仕訳8点セット（売上原価、貸倒引当金、減価償却、経過勘定、貯蔵品、現金過不足、有価証券、消耗品）
  - 精算表・財務諸表の作成手順
  - 試算表の作成

**Phase 0 の完了条件**: 3級の予想問題で **80点以上** が取れること。

### Phase 1: 商業簿記インプット1周（8/10 〜 9/13・5週・80時間）

テキスト → 該当章の問題集、を章ごとに交互に回します。**テキストを全部読んでから問題集、は絶対にやらないこと。**

| 週 | 期間 | 論点 |
|---|---|---|
| W1 | 8/10 - 8/16 | 商品売買の応用（売上原価対立法・クレジット売掛金・割戻）／現金預金・銀行勘定調整表／手形・電子記録債権 |
| W2 | 8/17 - 8/23 | 有形固定資産（割賦購入・資本的支出・除却・買換・圧縮記帳・建設仮勘定）／減価償却（200%定率法・生産高比例法）／リース取引／無形固定資産・ソフトウェア・研究開発費 |
| W3 | 8/24 - 8/30 | 有価証券（4分類）／引当金（貸倒・賞与・退職給付・修繕・商品保証）／外貨建取引・為替予約 |
| W4 | 8/31 - 9/6 | 株式会社会計（株式発行・剰余金の配当と処分・準備金積立）／株主資本等変動計算書／税効果会計／**収益認識基準（契約資産・契約負債・変動対価・返金負債）** |
| W5 | 9/7 - 9/13 | 本支店会計／**連結会計（資本連結・のれん・非支配株主持分・成果連結・開始仕訳・アップストリーム）**／決算と財務諸表作成 |

**山場は W4 の収益認識基準と W5 の連結会計。** ここは2級で最も脱落者が出るところなので、
- 連結は「**開始仕訳を書けるか**」がすべて。タイムテーブルを書く手順を型として覚える
- 1周目で完璧を目指さない。**「一度見たことがある」状態**まで持っていけば十分

**Phase 1 の完了条件**: 商業簿記の問題集を1周し、各章の基本問題に○がついていること。

### Phase 2: 工業簿記インプット1周（9/14 〜 10/4・3週・50時間）

**ここが合否を分けます。** 3級には存在しなかった分野ですが、範囲は商簿の半分以下で、パターンが安定しています。

| 週 | 期間 | 論点 |
|---|---|---|
| W6 | 9/14 - 9/20 | 工業簿記の全体像・**勘定連絡図**／材料費（予定消費単価・材料副費・棚卸減耗）／労務費（予定賃率・賃率差異）／経費 |
| W7 | 9/21 - 9/27 | 製造間接費の予定配賦・**シュラッター図（予算差異・操業度差異）**／部門別計算（直接配賦法・相互配賦法）／個別原価計算 |
| W8 | 9/28 - 10/4 | 総合原価計算（平均法・先入先出法／正常仕損・減損／度外視法）／工程別・組別・等級別／**標準原価計算の差異分析**／**直接原価計算・CVP分析**／本社工場会計／製造原価報告書 |

**工簿攻略の鉄則**
1. **必ず最初に勘定連絡図を描く。** 材料→仕掛品→製品→売上原価。すべての問題はこの図のどこかを問うているだけです
2. 総合原価計算は**ボックス図**、標準原価は**差異分析図**、製造間接費は**シュラッター図**。この3つの図を白紙から描けるようにする
3. 計算過程を必ず紙に残す。工簿は1箇所間違えると連鎖するので、検算できる形で書く

**Phase 2 の完了条件**: 工簿の問題集を1周。加えて、**Phase 1 の商簿を忘れないよう、この期間も毎日「仕訳10問」を必ず継続すること**（アプリ推奨）。

以下のどちらか**一方のシリーズで統一**すること。混ぜると用語と解法が食い違ってストレスになります。

## 5. つまずきポイント別・対処法

| 論点 | よくある詰まり | 対処 |
|---|---|---|
| 連結会計 | 開始仕訳が何をしているかわからない | 「前期までの連結修正を毎期やり直している」だけと理解する。タイムテーブルを必ず書く。動画解説を使う |
| 収益認識基準 | 契約資産と売掛金の区別がつかない | 「代金請求権が確定していれば売掛金、まだなら契約資産」。図で覚える |
| 税効果会計 | 繰延税金資産／負債の向きを間違える | 「会計上の費用が先・税務上が後 → 繰延税金資産」を型で暗記し、あとは問題演習量で慣らす |
| 製造間接費差異 | 予算差異と操業度差異が逆になる | シュラッター図を**毎回必ず書く**。暗算で処理しようとしない |
| 総合原価計算 | 平均法と先入先出法が混ざる | ボックス図を書き、月初仕掛品を「先入先出なら別枠、平均法なら混ぜる」と口に出して確認 |
| 標準原価差異分析 | 有利/不利の符号を間違える | 「実際が標準より多く使った＝不利」。必ず日本語で1回言い換えてから符号を書く |
| 時間切れ | 第2問で沼にはまる | 解答順を「1→4→5→3→2」に固定。第2問は最後の20分だけと決め、部分点狙いに徹する |

- 出題形式・配点・合格点は統一試験と同じ。ただし**画面上で解答するため、模擬プログラムでの練習が必須**
