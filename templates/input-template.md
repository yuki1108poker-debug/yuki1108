# 面談議事録作成 依頼フォーマット

議事録作成を依頼するときは、下記のコードブロックをコピーして各項目を埋め、Claude Codeに貼り付けてください。不明・未定の項目は空欄のままでOKです（Claude側で確認します）。

```
1. 面談先企業・目的：
2. 日時・場所・出席者：
3. 会社概要（事業内容・蝶理との関係・商流）：
4. 配布範囲（部内のみ／社外・海外含む）：
5. 前回TODO・継続論点：
6. 面談前アジェンダ（あれば）：
7. 特に強調したい点（あれば）：
8. 人物・雑談メモ（プロフィール欄用。南課長メモ等を含む）：
9. 課内コメントの扱い（自分で記載／ドラフト依頼）：
10. TODO形式（基本A：箇条書き＋担当者名。変更があれば記載）：
11. BELLSALESAIによる書き起こし：
（ここに書き起こし本文を貼り付け。複数ソースがある場合は「ソース①」「ソース②」等に分けて全て貼り付け。手書き補足があれば別途記載）
```

## 記入のヒント

| 項目 | 記入例・補足 |
|---|---|
| 1. 面談先企業・目的 | 例：昭和興産／リン酸の価格改定交渉 |
| 4. 配布範囲 | 「部内のみ」なら全6セクションのフル版、「社外・海外含む」なら部内フル版＋社外抜粋版（価格・プロフィール・コメント除外）の2本立てで出力されます。社外向け言語（日本語／英語／日英対訳）は別途確認します |
| 8. 人物・雑談メモ | 「5. プロフィール」欄に反映されます。完全に無関係な雑談は省略して構いません |
| 9. 課内コメントの扱い | 「自分で記載」を選んだ場合は空欄のまま出力、「ドラフト依頼」の場合はClaude側で叩き台を作成します |
| 11. 書き起こし | 添付ミス防止のため、面談先・日付が本文と一致しているか送信前に確認してください |

## 社内打合せ議事録（対顧客面談でない場合）

物流部・他部署との社内会議等は、上記フォーマットのうち「3. 会社概要」「8. 人物・雑談メモ」を割愛した簡易版で構いません。
